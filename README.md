## 🏗 Структура проекта

Проект разделен на логические блоки для удобства навигации:

* **`index.html`** — Точка входа, главная страница.
* **`photos/`** — Медиа-архив (работы, ткани, материалы).
* **`catalog/`** — Детальные страницы категорий услуг.
* **`js/main.js`** — Логика фронтенда и взаимодействие с API.
* **`server/`** — Node.js прокси-сервер для безопасности токенов.

## 🖼 Работа с изображениями

> [!IMPORTANT]
> Для соблюдения чистоты путей, следуйте правилу:

1.  Все фото хранятся в папке `/photos/` в корне.
2.  Если вы находитесь внутри папки `catalog/`, вызывайте фото так:
    ```html
    <img src="../photos/my-work.jpg" alt="Описание">
    ```

## 🚀 Развёртывание (Deployment)

### 1. Статика (GitHub Pages)
1. Создайте репозиторий `fantaziya-site`.
2. Загрузите файлы: `git push origin main`.
3. В настройках репо: **Settings** → **Pages** → **Branch: main** → **Save**.
4. Через 1-2 минуты сайт будет доступен по адресу вашего GitHub.

### 2. Бэкенд (Telegram Bot)
Для защиты вашего бота форма отправляется через сервер:
1. Деплой папки `server/` на **Render** или **Railway**.
2. Добавьте переменные окружения (ENV):
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
